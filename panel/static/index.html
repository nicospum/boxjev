    Subí lo que exportaron de Atom, HubSpot o WhatsApp. El sistema borra teléfonos, emails y nombres, clasifica cada conversación y crea un lote nuevo. No envía ningún mensaje. Para probar pocos contactos pegando el texto, usá Agregar lote.

    Agregar lote

    Pegá cada conversación tal como la copiás de WhatsApp, o escribila con «Cliente:» y «Ventas:» al principio de cada línea. Se borran teléfonos, emails y el nombre que indiques, y después Jev la clasifica.
